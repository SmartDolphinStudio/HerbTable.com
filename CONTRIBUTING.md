# Contributing to HerbTable.com

## Code Submission Rules

1. All code must pass linting before submission
2. Each PR must have at least one reviewer approval
3. Commit messages must follow conventional commits format
4. No secrets or credentials in code

## PR Process

1. Fork the repository
2. Create a feature branch from `main`
3. Make your changes
4. Run tests locally
5. Submit a pull request
6. Wait for code review approval
7. Merge after approval

## Code Review

- All PRs require at least 1 approval from a CODEOWNER
- CI must pass before merge
- No force pushes to main branch
