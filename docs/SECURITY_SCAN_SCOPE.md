# Security scan scope

Dependency alerts, automated security updates, secret scanning, and secret push
protection are configured on GitHub. The current source languages are
JavaScript/TypeScript and Go. CodeQL language and build support is documented
in the [official language support guide](https://docs.github.com/en/code-security/how-tos/find-and-fix-code-vulnerabilities/manage-your-configuration/codeql-for-compiled-languages).
An empty alerts response does not prove absence of vulnerabilities. CI and
scan results should identify the source commit.
